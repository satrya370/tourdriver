# Standar landing page tour guide / driver

Dirangkum dari riset 2026-11-12. Dipakai sebagai checklist untuk setiap template (bukan pengganti daftar section di plan).

Sumber: [Gondola, tour operator website design](https://gondola.travel/tour-operator-website-design/) · [Thrive Themes, travel homepage](https://thrivethemes.com/travel-homepage-design/) · [SquadTrip, tour guide website](https://www.squadtrip.com/guides/building-a-tour-guide-website-complete-step-by-step-guide/) · [Beacon Point, tour operator conversions](https://beaconpointhq.com/tour-operator-marketing-resources/designing-a-website-that-increases-visibility-and-conversions-for-tour-operators) · [Start Designs, 2026 guide](https://www.startdesigns.com/blog/travel-tourism-website-design-guide-2026/). Pengamatan langsung pada situs driver Bali (Putu Bali Driver, BaliCab, Wayan Ubud Driver) dan referensi pemilik (loka-bali, discova, lovebali).

## A. Layar pertama (termasuk mobile)
- [ ] Foto hero asli, penuh, emosional (bukan ilustrasi atau kotak kosong).
- [ ] Nilai jual dalam satu kalimat: siapa, di mana, apa.
- [ ] Tombol utama (WhatsApp) berwarna kontras, terlihat < 2 detik.
- [ ] Rating + jumlah ulasan di hero ("4.9 dari 180 ulasan Google").
- [ ] Satu lencana kepercayaan (Google / TripAdvisor / berlisensi).
- [ ] Harga "mulai dari" terlihat sebelum ajakan bertindak.
- [ ] Jaminan singkat (mis. pembatalan gratis, tanpa biaya tersembunyi).

## B. Ajakan bertindak
- [ ] Tombol booking di header, hero, tengah halaman, dan akhir halaman.
- [ ] Bar WhatsApp menempel di mobile; target sentuh ≥ 44 px.
- [ ] Booking tercapai ≤ 3 ketukan dari homepage.
- [ ] Kontak tampil di header dan footer, tidak perlu dicari.

## C. Bukti sosial (disebar, bukan satu halaman)
- [ ] Rating di hero + kutipan ulasan di dekat tombol booking.
- [ ] Lencana pihak ketiga (Google, TripAdvisor), ulasan bernama + asal + bulan.
- [ ] Foto tamu / galeri jika ada.
- [ ] Tidak memakai angka atau ulasan palsu.

## D. Harga dan keputusan
- [ ] Harga terlihat sebelum formulir/ajakan akhir.
- [ ] Jelas: termasuk, tidak termasuk, kapasitas mobil, jam kerja, biaya lembur.
- [ ] Kebijakan pembatalan terlihat (bukan hanya di FAQ).
- [ ] Pilih jenis perjalanan (kartu tur dengan durasi, rute, dan harga).

## E. Pemandu sebagai merek
- [ ] Foto ramah pemandu + bio singkat orang pertama.
- [ ] Kredensial: tahun pengalaman, bahasa, lisensi.

## F. Teknis
- [ ] Gambar WebP, < 200 KB per gambar, hero dengan `fetchpriority=high`.
- [ ] Skor Lighthouse mobile Performance ≥ 90.
- [ ] Mobile-first; paragraf pendek.
- [ ] Halaman minimum: Home, Tours, About, FAQ, Contact/Reviews (di situs ini: landing, tours, about, itinerary).
